VANTA NEXUS FORGE — Android PWA MVP 0.1 (Arctic Blue)

Публикация через GitHub Pages:
1. Создайте новый публичный репозиторий на GitHub.
2. Распакуйте архив и загрузите в корень репозитория ВСЕ файлы и папки из архива (не сам ZIP).
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите Deploy from a branch, ветку main и папку /(root), затем Save.
5. Дождитесь публикации и откройте адрес GitHub Pages в Chrome на Android.
6. В меню Chrome выберите «Установить приложение» или «Добавить на главный экран».

Важно:
- Это PWA, не APK. Для установки нужен опубликованный HTTPS-сайт.
- Проекты и идеи сохраняются в IndexedDB браузера на текущем устройстве.
- Очистка данных сайта может удалить локальные записи.
- Синхронизации с Windows-приложением и облаком пока нет.
